# algotrader

A small, tested backtester and experiment runner for strategies on US equity minute
and daily bars: SMA crossover, decision tree, gradient boosting, overnight holding,
intraday momentum, noise-area and opening-range breakouts, RSI(2) mean reversion,
time-series momentum, turn of the month, with optional volatility targeting and a
market regime filter; and portfolios over all tickers: cross-sectional momentum
(long-only and long-short), short-term reversal, pairs, machine-learning ranking, low
volatility, 52-week high, sector momentum and dual momentum. Written to replace an earlier, unverified set of scripts (see
[Removed legacy code](#removed-legacy-code)).

- `algotrader/` is the package, in a handful of small classes (see [Design](#design)).
- `tests/` has the unit tests (`pytest`, 334 tests, about 1.5 minutes).
- `STRATEGY.md` is the exact strategy and execution rules.
- `results/` holds the committed experiment results, regenerated by
  `python -m algotrader.experiments` (see [Experiments](#experiments)).
- `R&D/` has summaries and full Markdown text of research papers on intraday trading
  (`R&D/index.md`) and notes on the published strategies implemented here
  (`R&D/literature-strategies.md`). Their results are the authors' claims.

## Quick start

Dependencies are managed with [uv](https://docs.astral.sh/uv/): `pyproject.toml`
declares them, `uv.lock` pins exact versions and `.python-version` pins Python 3.10.

```bash
uv sync              # create .venv with the locked runtime + dev dependencies
uv run pytest        # run the unit tests
```

`uv add <pkg>` (or `uv add --dev <pkg>`) adds a dependency and updates the lock file;
commit both. Without uv: `pip install -e . pytest`.

Get data (next section), then run all experiments (tune on 2022-23, test on 2024 on;
results go to `results/`):

```bash
uv run python -m algotrader.experiments --list           # what exists
uv run python -m algotrader.experiments --workers 1      # everything (hours; see CLAUDE.md for the VPS)
uv run python -m algotrader.experiments orb_5min         # just one
uv run python -m algotrader.experiments --universe broad # 107 tickers -> results/broad/
```

Or backtest a single strategy on chosen tickers:

```bash
uv run python -m algotrader.run --data-dir data/scratch/tickers \
    --tickers ADM AMC AMGN --timeframe 5min --out data/results/summary_5min.csv

# decision tree: one model per ticker, fitted before --train-end, tested from it on
uv run python -m algotrader.run --data-dir data/scratch/tickers --strategy tree \
    --train-end 2024-01-01 --timeframe 1min --out data/results/tree_1min.csv
```

Omit `--tickers` to run every `*_clean.parquet` in the folder. `--help` lists all
options (`--strategy`, `--train-end`, `--max-depth`, `--fast`, `--slow`,
`--trend-filter`, `--atr-period`, `--atr-mult`, `--risk`, `--max-position`,
`--commission`, `--min-commission`, `--slippage`, `--capital`).

Or from Python:

```python
from algotrader import BarLoader, Backtester, Metrics

bars = BarLoader("data/scratch/tickers").load("AMGN", timeframe="30min")
result = Backtester().run(bars)            # default: SMA 20/50, 1% risk, IBKR commissions
print(Metrics(result, bars).summary())
print(result.trades_frame().head())

from algotrader import DecisionTreeStrategy
bars = BarLoader("data/scratch/tickers").load("AMGN", timeframe="1min")
train, test = bars[:"2023-12-31"], bars["2024-01-01":]
tree = DecisionTreeStrategy().fit(train)   # learn only from the earlier period
print(Metrics(Backtester(tree).run(test), test).summary())
```

## Data

The data is 1-minute OHLCV bars built from IEX trade reports (Mar 2022 to
present), from the **HF Data Library** (https://hfdatalibrary.com, maintained by
Ahmed Elkassabgi, CC-BY-4.0, for academic research, not for trading). The Hugging
Face repo `elkassabgi/hfdatalibrary` holds documentation only.

1. Register for a free API key at https://hfdatalibrary.com (name, institution,
   email, role, country). Keys expire every 30 days.
2. **Never commit the key.** Keep it outside the repo, for example in
   `~/.config/hfdatalibrary/token` (`chmod 600`).
3. Download an experiment universe (core: 27 tickers, about 200 MB; broad: 107,
   about 670 MB; existing files are skipped) or any tickers (full history, "clean"
   version, 5 to 8 MB each):
   ```bash
   uv run python -m algotrader.download --universe core
   uv run python -m algotrader.download --universe broad
   uv run python -m algotrader.download AAPL MSFT
   ```
   The key is read from `~/.config/hfdatalibrary/token` (`--token-file` to change)
   and never printed. The equivalent with curl:
   ```bash
   curl -H "X-API-Key: $(cat ~/.config/hfdatalibrary/token)" \
        -o data/scratch/tickers/AAPL_clean.parquet \
        "https://api.hfdatalibrary.com/v1/bars/AAPL?version=clean"
   ```
4. Available tickers (about 1,250, public): `https://api.hfdatalibrary.com/v1/symbols`.
   Limits: 100 downloads per minute.

Files have columns `datetime, Open, High, Low, Close, Volume, source`, with naive
US Eastern timestamps covering the regular session only (09:30 to 15:59).
`BarLoader` converts them to a `datetime` index with lowercase `open, high, low,
close, volume`. Intraday resampling is anchored to the 09:30 open, so `1h` bars run
09:30 to 10:30 and so on (the last bar of the day, 15:30 to 16:00, is a half bar).
Prices are split-adjusted by the provider (checked: no unexplained overnight jumps;
the gaps over 25% are earnings moves such as NFLX in April 2022).
`data/` and `.venv/` are git-ignored.

## Design

```
BarLoader ──bars──▶ Backtester ──▶ BacktestResult ──▶ Metrics
                      │  ▲  ▲  ▲        (equity, trades)    (summary stats)
                      │  │  │  └─ Strategy          (indicators, want_long)
                      │  │  └──── PositionSizer     (shares from risk/stop/cap)
                      │  └─────── CostModel         (commission, slippage)
```

Each class has one job and takes its collaborators in its constructor, so any of
them can be swapped or tested alone. A new strategy only has to satisfy the
`Strategy` protocol: an `indicators(bars)` method returning `want_long` and `atr`,
plus an `atr_mult` attribute (`tests/test_engine.py::AlwaysLong` is a minimal example).
Optional columns `stop_price`, `target_r`, `exit_at_close` and `size_frac` let a strategy
set its own stop, a profit target, be flat at a bar's close or cap its position size. To add it to the experiments, append an `Experiment` (bar
size, fixed parameters, tuning grid) to `EXPERIMENTS` in `experiments.py`.

### Execution rules (no look-ahead)

1. Signals are computed on a bar's **close** and filled at the **next bar's open**.
2. Entry only on a fresh crossover (`want_long` going False to True). After a stop-out
   the strategy waits for the next crossover instead of re-entering at once.
3. Stop = `atr_mult * ATR` below the entry fill (ATR from the signal bar), checked
   against each bar's **low**. Fill is the stop price, or the open if the bar gaps
   below it.
4. A position still open on the last bar is closed at that bar's close. Strategies
   can also close at a bar's close (`exit_at_close`) to stay flat overnight.
5. Equity is marked to the close of every bar. Sharpe uses **daily** equity returns
   (annualised with sqrt(252), risk-free rate 0).

See `STRATEGY.md` for the full specification.

## Experiments

`python -m algotrader.experiments` runs every registered strategy (35 experiments,
`--list`) over a universe (`algotrader/universe.py`): **core**, 27 tickers (4 index ETFs,
20 large caps, 3 original tickers; results in [`results/`](results/summary.md)), or
**broad**, 107 tickers (core plus 11 sector, bond and gold ETFs and a seeded random
sample filtered on March 2022 data only, including names that later stopped trading;
results in [`results/broad/`](results/broad/summary.md)). The main result is a
**walk-forward**: six folds starting every six months from July 2023; at each fold
start the parameters are chosen using only earlier data, then tested until the next
fold; the six test periods are concatenated (3.3 years, Jul 2023 to Oct 2026, all out
of sample). Single-ticker strategies start each ticker with $10,000 (the `_100k`
variants $100,000) fully invested when in a position, and report the equal-weight
portfolio of all tickers; portfolio strategies (`xs_*`, `pairs_daily`) run one $100,000
portfolio, and long-short ones pay a 50 bp/yr borrow fee. Costs are IBKR commissions
**plus a 2 bp half-spread per side** (also shown without costs, "gross", and with a
5 bp half-spread, "stress" in `results/`). The full tables, per-ticker and per-fold
CSVs, tuning grids, daily returns, trade logs and the code/data fingerprints are in
`results/`, committed with the code that produced them.

Reading:

- **No strategy shows an edge.** 389 configurations were tried per universe; the best of that many
  zero-edge strategies would reach a Sharpe of about 1.64 by luck over 3.3 years, and
  nothing clears it. Counting both universes (778, [`results/trials.md`](results/trials.md),
  `python -m algotrader.trials`) the bar is 1.75. No alpha is statistically significant (largest t-statistic 1.57).
- **Long-short momentum** (`xs_momentum_ls_daily`: long the 12-month winners, short the
  losers, monthly) is the only result that holds on both universes: Sharpe 0.96 and
  0.98, alpha +10.6% and +18.1% a year with beta 0.1 to 0.2, t 1.49 and 1.52, 6/6 and
  5/6 positive folds. But against the Fama-French factors plus momentum
  ([`results/factor_alpha.md`](results/factor_alpha.md),
  [broad](results/broad/factor_alpha.md)) it loads 0.40 and 0.77 on the momentum
  factor and its alpha falls to +3.0% and +3.4% (t 0.53 and 0.38): it is the known
  momentum premium, not anything new.
- **The SPY regime filter** lifted daily SMA and RSI(2) on core (Sharpe 1.42 and 1.35,
  alpha t 1.25 and 1.39) but not on broad (0.91 and 0.79, alpha about 0): not robust.
- **Daily trend rules** (SMA, RSI(2), time-series momentum) keep much of buy and
  hold's Sharpe with a third to a half of its market exposure, but their alpha is about
  zero: holding less of the market would have done the same.
- **Costs decide everything intraday.** Overnight holding (gross Sharpe 1.7 to 1.8),
  the 30-minute tree (1.3) and the opening-range breakout (0.5 to 0.9) lose their edge
  to a 2 bp half-spread; several intraday strategies have significantly negative
  alpha. The 1-minute tree's large gross edge (6.4 to 6.7) is many tiny trades and
  loses everything. Two refinements do not change that: a 10R profit target on the
  $100k ORB (`orb_5min_100k_target`, chosen in 3/6 core and 5/6 broad folds) gives 0.10 /
  -0.19, and skipping Monday nights in the $100k overnight hold
  (`overnight_1min_100k_weekday`, chosen in 5/6 folds on both) lifts it from 0.13 / 0.00
  to 0.42 / 0.47, alpha about 0 (t -0.22 / -0.13), still far from the luck bar.
- **Factor portfolios** (low volatility, 52-week high) match buy and hold's Sharpe on
  core (1.24, 1.30) with lower beta, but fall to 0.55 and 0.77 on broad; no alpha.
  **Dual momentum** is the reverse: 0.64 on core, 1.20 on broad with alpha +16.2% a year
  (t 1.57; +14.8%, t 1.47 against the factors, which hold no gold or bonds). GLD and TLT are only in broad, so on core it can only pick among SPY, QQQ and IWM
  and falls back to cash: the broad result depends on holding gold and bonds.
  Sector momentum (broad only) 0.85, no alpha.
- **A buy/hold buffer** on momentum (`xs_momentum_buffer*`, Novy-Marx & Velikov) changes
  little: core 1.19 / 1.05 (long-only / long-short, vs 1.12 / 0.96 without), broad 0.91 /
  0.76 (vs 0.98 / 0.98). Monthly momentum on large caps already trades little, so gross
  and net Sharpe differ by only 0.01 to 0.03; there is not much cost to save.
- **Multi-horizon trend on ETFs** (`trend_multi*`, Hurst, Ooi & Pedersen) is weak here:
  long-short 0.66 / 0.37, long or cash 0.83 / 0.86, no alpha. The published evidence is on
  dozens of futures markets; we have a few equity, bond and gold ETFs and 3.3 years.
- **The pre-holiday effect** (`pre_holiday_daily`, Ariel 1990) has no edge: Sharpe 0.17 /
  0.07, alpha about 0, gross 0.40 / 0.31 (about 9 holidays a year, so costs matter).
- **Machine learning** (pooled gradient boosting, cross-sectional ranking) does not beat
  the simple rules on either universe.
- The broad universe is harder: buy and hold and most strategies are lower, and pairs
  trading turns negative (-0.73) where it was 0.64 on core.

## Long history (2008 to Oct 2026, S&P 500 members)

`python -m algotrader.longrun` (and `longrun_chart`) walk forward over 14.8 years (yearly folds from
2012; chart CNN from 2014; deep arbitrage from 2013) on the point-in-time S&P 500 universe, $1M, the
same costs, adjusted prices from Tiingo, else the adjusted Hugging Face daily series, else WIKI. Full
tables (26 experiments): [`results/long/summary.md`](results/long/summary.md), factor regressions
[`results/long/factor_alpha.md`](results/long/factor_alpha.md); the same run without the Hugging Face
series is in `results/long_nohf/`. Buy and hold of SPY over the same days: Sharpe 0.93, +15.0% a year.

- **Long-only strategies match the market, they do not beat it.** Sharpe 0.5 to 0.9 (operating
  profitability 0.86, high 52-week 0.81, profitability 0.81, pead 0.79, momentum 0.79, low volatility
  0.78, asset growth 0.77, value 0.63), all with beta about 1 (low volatility 0.61) and alpha against
  SPY between -5.7% and +1.3% a year, none significant (largest |t| 1.79). Against the Fama-French five
  factors plus momentum no strategy has a positive alpha t-statistic above 0.76 (a long-short asset-growth sort).
- **Long-short portfolios earn nothing** after costs (Sharpe -0.35 to +0.11): momentum 0.03 (it
  loads 0.61 on the momentum factor, alpha -2.3% a year, t -1.07), value -0.01, profitability -0.18.
- **Price-chart CNN** (small network): long 0.54 (alpha -3.4%, t -1.40), long-short -0.01; turnover
  about 1,100% a year.
- **Deep arbitrage fails with next-open execution**: Sharpe -5.37 (-4.79 without the Hugging Face
  series), 0 of 14 folds positive, turnover 2,677% a year. Gross Sharpe is -0.15, so even before costs
  there is nothing (see ROADMAP S8: the paper trades at the close).
- **Luck bar:** 1,207 configurations in all (129 here, 44 in the stop-loss test, 138 in the concentration test, 60 in the weekly
  test, 58 in the mid-cap test); the best zero-edge one would reach a Sharpe of about 0.86 over 14.8 years ([`results/trials.md`](results/trials.md)). No long-history result clears it above SPY's 0.93.
- **Combined signal and trend filter** (`combo.py`, 5 more experiments): blending momentum, low
  volatility, 52-week high and profitability gives long-only 0.69 (price signals only 0.75), alpha
  -1.3% a year (t -0.60) and long-short -0.24: blending does not create an edge. Holding the
  combined signal only while SPY is above its 200-day mean gives Sharpe 0.71 and CAGR +7.6% with a
  maximum drawdown of -18.1% (-32.8% without the filter), beta 0.39: it lowers risk by holding less of
  the market, alpha +1.9% a year (t 0.80, not significant). Filtered momentum 0.56 (drawdown -26.4%).
- **Blending the strategies** (`scripts/strategy_blend.py`, `results/long/blend.md`, 25 strategies, 2014 to 2026, SPY Sharpe 0.83
  over those days): equal-weight long-only 0.71, inverse-volatility 0.70, all long-short about -0.13, long-only plus
  long-short 0.70 with max drawdown -24% (SPY -34%) and beta 0.53, inverse-vol of everything 0.67 with drawdown -14% and
  beta 0.32. Long-only strategies are 0.73 correlated, so they diversify little; the long-short ones are uncorrelated
  with everything (0.02 to -0.04) but each earns about zero, so averaging them adds up to zero. Blends lower the
  risk by holding less of the market, not by adding return: alpha stays near zero (all |t| < 1).
- **Stop-losses** (`stoploss.py`, `longrun_stop.py`, [`results/long_stop/summary.md`](results/long_stop/summary.md); momentum,
  low volatility, 52-week high and the combined price signal, each with no stop or a 10-30% fixed or trailing stop, 44
  configurations): **every stop gives up more gain than the loss it avoids.** 60-87% of the stopped stocks were higher at the
  next monthly rebalance than where they were sold; the gains given up were 1.5 to 16 times the losses avoided (net -0.1% to
  -9.5% of the portfolio a year). What stops do buy is a smaller drawdown at about the same CAGR on the slow strategies: low
  volatility with a 15% trailing stop Sharpe 0.92, CAGR +10.4%, max drawdown -18.6% (no stop 0.80, +10.5%, -34.9%), 52-week high
  with 20% trailing 0.86, +11.2%, -21.7% (no stop 0.80, +11.0%, -30.9%); CAGR holds up despite the negative net because the lower
  volatility costs less compounding. On momentum tight stops hurt (10% trailing: +7.9% a year against +15.9%) and the walk-forward
  chose no stop or 30% in 13 of 15 years. The Sharpe gains (0.05-0.12) are well inside the noise; like the trend filter, a stop
  trades return-free risk reduction, not an edge.
- **How many stocks to hold** (`concentration.py`, [`results/long_conc/summary.md`](results/long_conc/summary.md); eleven
  long-only strategies at top 3, 5, 10, 20, 50, rank bands, buy/hold buffers and multi-strategy portfolios, 138 configurations):
  **fewer stocks do not earn more in general.** Pre-registered rule (top 3 or top 5 minus top 50 with Fama-French alpha t >= 2,
  for most strategies): 2 of 11 pass (momentum top 3 +12.3% a year, t 2.14; asset growth top 5 +9.6%, t 2.47), about what 22
  tests give by chance. Averaged over the strategies, Sharpe falls as N shrinks (top 50 0.74, 20 0.71, 10 0.67, 5 0.62, 3 0.55) at
  about the same CAGR (+11.8% to +12.9% a year) with more volatility (17% to 25%) and deeper drawdowns (-38% to -46%). The top
  three ranks beat ranks 21-50 only for momentum (+17.6% a year, t 2.60); on the combined price signal they are significantly
  worse (-10.9%, t -2.76). A buffer (buy the top 5, sell only when out of the top 20) cuts turnover (by half or more on 5 of
  11, little on earnings drift and seasonality) but does not raise Sharpe (on 7 of 11 it is lower); monthly large-cap trading
  costs little to begin with. Combining:
  all eleven at top 5 each Sharpe 0.91 (+14.0% a year), the best five chosen each January on earlier data 0.95 (+15.6%), with the
  buffer 0.91, the single best strategy chosen each January (operating profitability every year, so the same as holding it) at top 5 1.04
  (+18.9% a year, Fama-French alpha +5.2%, t 1.73), SPY 0.93 (+15.0%). None is significant; the 1.04 is one of 138 tries
  against a luck bar of 0.86 above SPY's level, with a 90% interval of 0.63 to 1.51.
- **Weekly instead of monthly rebalancing** (`rebalance.py`, [`results/long_rebal/summary.md`](results/long_rebal/summary.md); ten
  strategies at top 5, top 20 and the top 5 / keep-in-top-20 buffer, 60 configurations): **no better.** Pre-registered rule (weekly
  minus monthly with Fama-French alpha t >= 2 for most strategies): 0 of 10 pass. Averaged over the strategies weekly checking
  roughly doubles turnover (top 20: 410% to 959% a year) for the same or lower Sharpe (top 5: 0.59 both; top 20: 0.72 to 0.68 at
  base costs, 0.71 to 0.65 at stress) and CAGR (top 20 +12.2% to +11.6% a year). Even before costs it adds nothing (top 20 gross
  0.74 to 0.72). Largest gain momentum top 5 (+3.7% a year, t 1.60); largest loss earnings drift (-2.3% to -3.3% a year, its signal
  is stale by the next week). Operating profitability top 5: 1.04 monthly, 1.01 weekly.
- **Run-to-run noise in the portfolio engine (found 2026-10-20):** `PortfolioBacktester` processes the day's buys in set order,
  which changes with Python's hash seed; the last buy absorbs the cash shortfall from gaps and costs, so identical code and data
  give slightly different results. Most strategies agree to 0.01 Sharpe between the concentration and the weekly runs, but the
  momentum-based top 5 portfolios differ by up to 0.24 (momentum 0.83 / 0.77, combined signal 0.33 / 0.09): differences of that
  size between such configurations are noise. Fix pending (ROADMAP 14).
- The Hugging Face series changes a Sharpe by a median 0.06 (largest 0.58, `deep_arb_long`).

## Mid-cap test (2008 to Oct 2026, ex-S&P 500)

`python -m algotrader.midcap` runs eight pre-registered price-based strategies on the stocks ranked 1-1,500 by dollar volume
minus the S&P 500 (about 1,040 names a month, `sizeuniverse.py`), adjusted Hugging Face prices, 5 bp half-spread (10 bp stress).
Rule fixed before the run: **a Fama-French alpha with t >= 2 at base costs, a Sharpe above the equal-weight universe and still
positive at stress costs.** Full tables: [`results/mid/summary.md`](results/mid/summary.md),
[`results/mid/factor_alpha.md`](results/mid/factor_alpha.md). Over the same 14.8 years SPY had Sharpe 0.93 (+15.0% a year) and
the equal-weight universe 0.50 (+8.7%, no dividends after 2018).

- **Verdict: fail.** No strategy has a Fama-French alpha with t >= 2; the best is momentum, +4.2% a year (t 1.13).
- Momentum (Sharpe 0.78, +19.7% a year, max drawdown -37%) and the combined price signal (0.76, +15.0%) beat the equal-weight
  universe (alpha +10.9% and +8.6% a year, t 2.37 and 2.25) and stay positive at 10 bp, but that alpha is exposure to known
  factors: momentum loads 0.58 on the momentum factor and 0.75 on small size, and against the factors its alpha drops to +4.2%
  (t 1.13), the combined signal's to +0.8% (t 0.27). Neither beats SPY's Sharpe.
- 52-week high 0.64, low volatility 0.49, seasonality 0.39, momentum long-short 0.31, reversal 0.13 and seasonality
  long-short -0.44; low volatility and both seasonality strategies have significantly negative factor alpha (t -2.4 to -2.5).
- The backtests lack dividends after March 2018 (about 1-2% a year for mid-caps) while the factors include them, so the
  alphas are understated by about that much; momentum's would still be about t 1.5.
- The first run crashed on bad data (exchange test symbols, negative and near-zero adjusted prices) after printing momentum's
  Sharpe as 0.26; the fixed data gives 0.78 with the same strategies and rule (see STRATEGY.md).

## Earlier exploration (3 tickers)

Default strategy (SMA 20/50, 1% risk, 2x ATR stop, 10% max position, IBKR
commissions, no slippage), $10,000 start, 3 tickers, Mar 2022 to Oct 2026. These
tickers are those in the legacy results file, not a chosen sample. Produced with
`python -m algotrader.run`; superseded by the experiments above.

| Bar size | ADM | AMC | AMGN | Trades per ticker | Time in market |
|---|---|---|---|---|---|
| 1 min | -82.1% | -68.8% | -67.3% | 3,500 to 4,300 | 26% to 30% |
| 5 min | -12.1% | -28.9% | -16.4% | about 1,000 | 27% to 34% |
| 30 min | -3.0% | +7.0% | -3.7% | about 160 | 32% to 33% |
| 1 hour | -3.1% | -0.9% | +2.2% | 80 to 94 | 29% to 38% |
| 1 day | +1.8% | -9.8% | +2.3% | 13 | 13% to 47% |
| Buy and hold | -2.3% | -98.2% | +88.3% | | 100% |

Reading: on short bars the crossover whipsaws constantly and the $1 minimum
commission (on roughly $1,000 positions) costs about 0.2% per round trip, which
dominates. On 30 min and daily bars the result is indistinguishable from noise.
Buy and hold is not a like-for-like benchmark: positions are capped at 10% of
equity and are open only about a third of the time, so on average roughly 3% of
capital is in the market. That shrinks both the gains and the losses.
**There is no demonstrated edge here**; this is a working, trustworthy baseline to
test better ideas against, not a profitable strategy. Three tickers is far too
small a sample for any conclusion.

### Decision tree (arXiv:2405.13959)

Reproduction of the decision-tree paper (`R&D/`) with our engine: one tree per ticker
(depth 4, Gini), trained on Mar 2022 to Dec 2023, tested Jan 2024 to Oct 2026 (out of
sample). Same 3 tickers, $10,000 start. "Paper-like" means fully invested
(`--max-position 1 --risk 1`) with the stop effectively off (`--atr-mult 50`); the
paper used no costs and no stop. Buy and hold over the test period: ADM +14.7%,
AMC -50.4%, AMGN +51.8%.

1-minute bars (the paper's setting):

| Setup | ADM | AMC | AMGN | Trades (ADM / AMC / AMGN) |
|---|---|---|---|---|
| Paper-like, no costs | +27.6% | +10.5% | +92.4% | 7,052 / 337 / 43,076 |
| Paper-like, IBKR commissions | -99.3% | -67.9% | -97.4% | |
| Paper-like, IBKR + $0.01/share slippage | -99.5% | -97.5% | -97.5% | |
| Defaults (1% risk, 2 ATR stop, 10% cap), IBKR | -93.5% | -10.4% | -74.3% | |

Other bar sizes, paper-like:

| Bar size | No costs (ADM / AMC / AMGN) | IBKR (ADM / AMC / AMGN) | Time in market |
|---|---|---|---|
| 5 min | +47.6% / +68.9% / +4.9% | -58.0% / -100.0% / -10.3% | 4% to 9% |
| 30 min | -2.2% / -0.2% / +53.3% | -13.5% / -27.0% / +38.5% | 1% to 93% |
| 1 hour | -10.0% / +18.8% / +47.7% | -16.6% / -55.0% / +37.4% | 8% to 82% |

Reading: on 1-minute bars the tree does find something before costs (win rate about
52%, profit factor about 1.06), but it is worth only **0.15 to 0.35 basis points per
trade** (ADM, AMGN). The $1 minimum commission on a $10,000 position is 2 bp per round
trip, and a one-cent spread on a $60 stock is about 1.7 bp per side, so the edge is
roughly ten times too small to pay for trading. A larger account only removes the $1
minimum: the per-share commission alone is $0.005 / price per side, 0.8 bp on ADM
(about $60) and 0.17 bp on AMGN (about $300), so the round trip still costs more than
the edge before any spread. The gross edge may well be
bid-ask bounce in trade prints rather than anything tradeable (not tested). On 30 min
and 1 hour bars the tree is mostly long and tracks the market, never beating buy and
hold after costs. AMC's trees rarely go long (the training period was a steady
decline). **The paper's result does not survive realistic costs here.**

## Limitations

- The single-ticker engine is long only; only the portfolio engine can short (no
  margin calls or recalls, a flat borrow fee). Whole shares, no leverage.
- Walk-forward over 3.3 years of test data, with a short history before it (from
  March 2022): slow strategies get few trades to tune on.
- The core universe is today's large caps (survivorship bias). The broad universe is
  sampled from the provider's current symbol list, so it only includes delisted names
  the provider still lists. Compare with buy and hold of the same tickers.
- Per-share commissions use split-adjusted prices, so they are overstated before a
  split (NVDA, NFLX, WMT...) and understated before AMC's reverse split.
- No bid-ask spread by default (`--slippage` adds one); fills at bar open/close prints.
- Exposure counts bars that END in a position, so overnight holds show about 0%.
- IEX volume is a small share of the consolidated tape; fills are assumed at the
  quoted bar prices with no market impact or partial fills.
- Clean-version data has some bars removed by the provider's outlier filter.
- Prices are as provided; corporate-action handling is the provider's. Check before
  trusting long histories.
- **Not all of it is tradable from an EU retail account** (PRIIPs: no US-domiciled ETFs,
  see `ROADMAP.md`). The core universe holds 4 index ETFs (SPY, QQQ, IWM, DIA) and broad
  adds 11 sector, bond and gold ETFs, so every single-ticker experiment includes ETF
  trades; dual momentum, multi-horizon trend, sector momentum and the SPY/DIA and
  QQQ/XLK pairs trade only or mainly ETFs. The long-history experiments trade S&P 500
  stocks only (SPY is just the benchmark).
- Results are pre-tax (the Spanish two-month rule on repurchased losses is not modelled).
  Not investment advice.
