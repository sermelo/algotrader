# Intraday FX Volatility-Curve Forecasting with Functional GARCH Approaches

**Authors:** Yuqian Zhao (and co‑authors)  
**Affiliation:** Macquarie University (Australia), University of Sussex (UK)  
**arXiv:** [2311.18477v3](https://arxiv.org/abs/2311.18477v3)  
**Date:** 30 Sep 2025  

## Abstract
This paper forecasts intraday volatility curves for major FX pairs (USD/EUR, USD/GBP, USD/JPY) using functional GARCH models that treat the entire intraday return curve as a functional observation. By incorporating functional principal component analysis (FPCA) to capture cross‑currency dependence and adding bid‑ask spread curves as exogenous drivers, the model achieves superior volatility forecasts compared to baseline functional and realized‑volatility approaches. The resulting intraday VaR forecasts can be used to mitigate losses in intraday trading strategies.

## Summary
The work treats each day's intraday return path as a random function and applies a GARCH‑type dynamics in a functional space. Dimension reduction via (multilevel) FPCA captures the dominant modes of cross‑currency variation, while exogenous spread curves improve forecast accuracy. The proposed framework yields reliable intraday Value‑at‑Risk estimates, offering a practical risk‑management tool for high‑frequency FX traders.
